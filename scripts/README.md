`stack-env.sh` is how a program on this computer finds the stack:

```bash
scripts/stack-env.sh env
```

prints, among others, `DATABASE_URL`, `REDIS_URL`, and the `STACK_` addresses
the end-to-end suite uses. It reads `infra/.env` as text and never runs it.

Scripts here are Bash or plain Node with no packages to install, start by
moving to the repository's root, and stop at the first error. Four need
something more. `screenshots.mjs` needs Google Chrome or Chromium on the
computer, `mac-app.sh` needs a Mac with Apple silicon and Apple's command
line tools, `windows-app.sh` needs 64-bit Windows with Git Bash and
Microsoft's C++ build tools, and `linux-app.sh` needs 64-bit Linux with
WebKitGTK, OpenSSL, and a C compiler. No test starts the browser or builds the app.
