# apps

Programs a person opens and uses. Servers live in [services](../services),
and code shared between programs lives in [packages](../packages).

| Folder             | What it is                                          |
| ------------------ | --------------------------------------------------- |
| [desktop](desktop) | The chat window for macOS, and later Windows        |

A new app gets its own folder here, with its own README, and builds without
needing any other app.
