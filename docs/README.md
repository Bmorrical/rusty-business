# docs

Pictures the READMEs show.

| File               | What it is                              | Shown in                                   |
| ------------------ | --------------------------------------- | ------------------------------------------ |
| `chat-window.webp` | The chat window with a question answered | The root README and [apps/desktop](../apps/desktop) |
| `rusty-business.svg` | The banner: the name, a person wobbling on top of a stepladder, and two rusty nails on the ground | The root README |

The banner is the project's artwork. [TRADEMARKS.md](../TRADEMARKS.md) says
how it may be used.

How a part works is written in that part's own README, beside its code, so
the two change together. This folder holds only what those READMEs point to.

A picture added here gets alt text where it is shown, and a row in the table
above.
